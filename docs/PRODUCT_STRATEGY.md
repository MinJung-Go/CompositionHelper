# 产品定位与买断路线

更新：2026-09-10。用户已确认方向：核心功能全部买断，AI 使用用户自己的 Key，并在本机安全保存以减少重复填写。支付、Key 持久化和新手引导尚未实现。此方向取代上一轮“Pro + AI 次数包 + 小后端”的建议。

## 1. 产品定位

轻量原生摄影工具：帮助普通手机摄影用户从取景、构图到自然调色，完成一张满意的照片。日常记录、旅行与美食摄影初学者是待验证的目标人群。已有构图建议、手动调色、原图对比和真人检查清单构成工具价值；AI 为可选的拍后辅助。

产品采用一次付费解锁全部核心功能的买断制，不订阅，不销售 AI 次数包，不建立运营方 AI 余额。使用本地功能不需要注册本应用账号，也不需要先设置 AI。

“买断”覆盖已购买的工具功能使用权，AI 连接能力也属于工具；第三方模型的账号、可用地区、额度和可能产生的费用由供应商规则决定。购买页必须在付费前说明这个边界，不以“终身免费 AI”宣传。

## 2. 收费与分发

建议渠道实现为免费下载体验后，一笔非消耗型内购解锁全部核心工具；体验限制另行确定，不继续拆卖核心功能。若后续选择 App Store 付费下载，也保持同一买断承诺，但二者应在上架前选定一种，避免重复收费。[Apple 商业模式](https://developer.apple.com/app-store/business-models/)

默认开发路线保留 StoreKit 非消耗型商品：商品价格来自 StoreKit、权益验证与恢复在设备上完成。本地功能可以在离线时继续使用已有有效权益；首次购买或恢复可能需要网络。iOS 正式收费版走 App Store 与 Sandbox/TestFlight 验证，iloader 继续只用于开发测试。[StoreKit 2](https://developer.apple.com/storekit/)

首期不建设用户账户服务、购买服务器、AI 代理、积分账本或云相册。可以使用静态帮助页、隐私政策和支持邮箱，它们不接收 Key 或照片。Android 保持功能和 BYOK 行为一致，收费渠道单独确认，不自动承诺跨平台购买互通。

## 3. AI 配置的体验目标

目标为“首次引导，主动粘贴保存，之后自动使用”，不要求用户理解 endpoint、JSON、温度或 token 等参数。首次打开 AI 设置仅显示三个动作：

1. **获取我的 Key**：打开供应商官方页面，在官方页面登录/注册。
2. **粘贴 Key**：回到应用，用户主动粘贴，应用做本机格式检查。
3. **保存到此设备**：系统安全存储成功后显示“已保存”；用户主动点击 AI 调色时才发送照片并验证实际调用能力。

允许用户直接粘贴已有 Key，跳过教程。提供“稍后设置”，本地工具正常使用。供应商和模型使用经过验证的默认配置，模型名称放入高级设置；保存成功不冒充已验证账户额度或照片处理能力。

Key 是供应商调用凭据，不是本应用的付费激活码；填入 Key 不能替代购买或解锁付费权益。获取入口只用于第三方账号配置，具体商店审核说明必须如实描述 BYOK 模式。

详细流程、错误处理与验收见 [BYOK 新手引导](BYOK_ONBOARDING.md)。

## 4. “尽量简单”的真实边界

当前实现仅支持 Gemini。Google 官方说明，新 AI Studio 用户接受条款后可得到默认项目和 Key；已有 Cloud 账号通常需要导入项目，组织账号还可能受权限影响。这能减少新用户步骤，但我们没有验证或承诺“一键替用户注册并取得 Key”。Google 账号注册、验证和条款确认必须由用户在官方页面完成。[官方 Key 指南](https://ai.google.dev/gemini-api/docs/api-key)

目前无法把第三方网页注册步骤全部消除。应用可以提供官方直达入口、简短图文说明、系统粘贴与可读的错误提示。不要做自动登录、收集供应商密码、后台读取剪贴板或把 Key 放进回跳链接。

新用户可能有模型免费配额，但不保证所选模型、地区和个人账号始终免费可用。相册照片的数据用途也需要注意：免费和付费 API 的处理条款不同，不能为了少一步配置而隐藏照片上传和数据用途说明。[计费说明](https://ai.google.dev/gemini-api/docs/billing)、[数据条款](https://ai.google.dev/gemini-api/terms)

## 5. 地区与供应商选择

首发地区待用户确认。对于能正常使用 Gemini 的目标市场，优先优化现有 Gemini 引导。如果主要面向中国大陆，需要另行评估适合该市场的图像模型、官方注册与 Key 获取流程，再选择默认供应商；不能用海外代理作为默认解决办法，也不能宣称目前已经支持其他供应商。[Gemini 地区范围](https://ai.google.dev/gemini-api/docs/available-regions)

“最简单”应以真实新用户在目标地区完成首次配置的成功率和时间判断。候选供应商需要验证：当地可访问、注册要求、是否能在手机上取 Key、是否需开通计费、图片理解与结构化流式输出能力、照片数据条款。首屏只突出一个适合该市场的已验证选项，不堆满未经测试的模型列表。

## 6. 实施顺序与验收

| 阶段 | 交付 | 验收 |
|---|---|---|
| A | Key 安全持久化、替换/清除、默认模型记忆 | 重启和重新打开编辑器后无需重复输入；保存失败明确提示；两端不明文落盘 |
| B | 官方获取入口、三步引导、系统主动粘贴、错误分流 | 目标地区新用户可完成首次配置；没有 Key 仍能使用本地工具 |
| C | 单笔买断商品、权益恢复、购买说明 | StoreKit 取消、pending、恢复、撤销与离线用例通过 |
| D | 上架准备和真机验证 | 核心成片闭环、流式 AI、隐私说明与产品承诺一致 |

已有用户的 Key 是敏感信息，验收截图和日志均不包含明文。iOS 重新签名/应用标识变化、设备迁移或 Key 被供应商撤销后，可能需要重新配置；“记住此设备”不承诺永久跨设备同步。

本轮更新产品和架构约定，没有实施支付或安全存储。当前 App 实际功能仍以 [交付记录](RELEASES.md) 为准。
