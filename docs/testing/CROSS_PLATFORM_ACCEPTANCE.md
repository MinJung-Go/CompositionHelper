# 安卓 / iOS 功能统一与测试验收清单

更新：2026-10-26。核心功能采用下表约定。代码对齐、自动测试通过和双端真机通过分别判定，不互相替代。

## 统一的功能与行为

| 功能 | 两端约定 | 验证方式 |
|---|---|---|
| 构图工具 | 同名的 19 种构图、3 个分类，颜色、透明度、黄金螺旋方向 | 枚举对照及真机逐项查看 |
| 相册构图分析 | 默认相机可以打开独立相册分析页，并可返回实时相机 | 两端从默认首页实际操作 |
| 拍照后流程 | 保存原片成功后进入调色；调色另存副本，不覆盖原片 | 保存授权、拒绝、重试、相册核对 |
| AI 调色 | GLM / Gemini；默认 GLM-5.3-Flash；切换供应商清空旧 Key | 协议测试与真实 Key 调用 |
| 流式预览 | 仅完整且有效参数生成临时图；临时阶段禁止保存；失败或取消保留正式配方 | 核心回归和设备操作 |
| 手动调色 | 相同的基础七参数范围、RGB 原色/互补色、四个明暗范围及 RGB 重置 | 参数范围对照、参考像素回归 |
| 离线基础调整 | 用户主动触发；相同统计规则；可撤销，不请求 AI | 两端相同 offline_reference.json 用例 |
| Key 生命周期 | 当前应用进程内保留；关编辑器后仍可使用；退出进程清除；无明文持久化 | 关编辑器、重开、清除、重启进程 |
| 大图导出 | 原图不超过 3200 万像素可按原尺寸导出；超过上限可预览但明确拒绝导出 | 边界、超限和整数溢出回归 |
| 样片 | 相同的四张照片及来源 | 文件哈希与实际打开 |
| 拍摄检查清单 | 3 组 12 项、4 种人工状态、本机备注、分享导出、确认后重置 | JSON/原生条目对照与设备操作 |

## 自动检查

- Android CI：Debug APK、设备测试 APK 编译、JVM 回归及 lint；报告随运行上传。
- iOS CI：调色核心回归、模拟器编译、空状态/小屏/大字体/清单截图。
- iOS IPA 工作流：未签名 Release 包。可编译不代表可直接安装或已完成商店发布。
- 离线参数和调色像素各有同源固定输入，逐端执行，不能用一端成功替代另一端。
- 本轮的执行状态及链接记录在 RELEASES.md，历史记录不作为新提交的成功证据。
