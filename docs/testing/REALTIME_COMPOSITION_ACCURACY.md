## 本轮目标

根据[实拍验证报告](REALTIME_COMPOSITION_VALIDATION.md)，改善主对角线漏检、人像构图定位和多人主体跳变。验收分别统计单帧候选、稳定后的提示、原生检测与实际设备表现。

## 实现

- 对角线仍使用 Android OpenCV LSD、iOS Vision 轮廓。把短缺口两侧的共线线段合并，检查真实覆盖、方向、是否贯穿画面中部及双侧同向亮度差。拒绝只有半边的透视汇聚线、缺乏亮度边界的细线及多组近似平行长边。每帧最多评估 24 条种子线段。M-LSD 保留在离线对照中。
- Android 使用随包分发的 ML Kit 人脸检测，iOS 使用系统 Vision 人脸关键点。优先采用双眼都落在可见画幅内、间距和姿态合理的人脸。合影按相邻帧的脸框重叠和锚点距离关联，连续失配才重新选人。没有可信双眼时用原平台的通用主体检测。可靠的人像位置与其他构图证据走原来的推荐评分。
- 两端沿用 200 ms 采样间隔和两帧推荐稳定逻辑。相机退出、重绑及画幅变更按原有生命周期重置识别状态。Android 新增随包人脸库，需检查最终 APK 的 16 KiB 对齐与运行。
