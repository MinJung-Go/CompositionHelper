# 双端实时构图检测

R1 · 在相机智能模式中更快地给出稳定、有画面证据的推荐。范围为 Android CameraX 和 iOS AVFoundation 实时预览，沿用现有推荐控件、手动辅助线和拍照流程。

- 每 200 ms 最多分析一帧，繁忙时丢弃旧帧。连续两次得到同一候选才显示、切换或撤回推荐。
- 依据可见取景框内的主体位置判断居中和三分法。对角线需要可见的长斜线，其方向和位置都应接近辅助线。Android 保留 ML Kit，并使用 OpenCV LSD；iOS 保留 Vision 人脸和矩形检测，并从简化轮廓提取线段。iOS 现有充满画面和负空间规则继续参与评分。
- 缺少可靠证据时撤回推荐。退出智能模式后丢弃旧帧结果。全部分析在端侧进行。
- 验收样例包含居中主体、三分点主体、无主体长斜线、仅有短斜线、无证据、瞬时误判以及不同画幅下的取景框裁切。用实际设备检查首次提示延迟、预览流畅度、误报和提示跳变。

本轮沿用现有界面设计。变更集中在推荐数据、取景坐标和生命周期。
