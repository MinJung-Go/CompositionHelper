# 自带 API Key：首次配置与安全保存设计

更新：2026-09-10。实施规范，尚未落地到界面或存储代码。目标：买断核心工具后，AI 只需首次配置；不建设账号/密钥/计费后端。

## 用户看到的页面

页面标题“连接你的 AI”，说明：“使用你自己的 AI 服务。Key 安全保存在此设备，模型费用和额度由服务商决定。”

| 状态 | 主操作 | 说明 |
|---|---|---|
| 没有 Key | 获取我的 Key / 我已有 Key | 可以稍后设置，继续本机编辑 |
| 查看帮助 | 打开官方页面 | 只显示登录、获取/复制、返回粘贴三个步骤 |
| 输入 | 系统粘贴 / 手动输入 | 默认隐藏内容，不要求填写服务地址或模型 ID |
| 保存 | 保存到此设备 | 明确说明保存用途；写入安全存储成功才显示已保存 |
| 已配置 | 更换 / 清除 | 默认显示已配置与供应商，不回显完整 Key |
| 调用失败 | 按错误给出下一步 | 保留已保存 Key；不把每个错误都当作密钥错误 |

“已保存”与“可成功调用”是不同状态。保存只进行长度、空白和字符等本机检查，不暗中发起收费模型探测，也不自动上传照片。第一次真实 AI 调色时验证权限和模型能力；失败不能自动删除用户的凭据。

## Gemini 最短官方流程

官方帮助入口：[创建与管理 Gemini Key](https://ai.google.dev/gemini-api/docs/api-key)。应用中的直达地址可使用 `https://aistudio.google.com/apikey`，但上线前需要在目标设备和地区验证重定向；如果链接变更，帮助页提供回到官方指南的入口。本次未在登录后的手机页面实走流程。

1. 用自己的 Google 账号登录 Google AI Studio；没有账号时在 Google 官方页面注册，并自行完成可能要求的验证与条款确认。
2. 在 API Key 页面复制自己的 Key。官方说明，符合条件的新用户有默认项目和 Key；已有 Cloud 项目用户可能需要先导入项目或创建 Key，放在“没有看到 Key？”帮助中。
3. 切回应用，点击系统粘贴，然后保存到此设备。

这些步骤依据官方文档设计，不承诺所有账号都只需要三次点击。当前新建 Key 类型和供应商入口可能变化，避免在应用中硬编码 Key 必须有某个前缀或固定长度。[官方说明](https://ai.google.dev/gemini-api/docs/api-key)

首屏不要求安装 Google Cloud CLI、创建服务账号、填写环境变量或复制命令。组织账号无权限时明确提示联系管理员或按官方流程使用有权限的个人项目，不反复让用户换密钥。

## 应用内可以简化的部分

- iOS 使用系统浏览器或系统浏览器组件；Android 使用系统浏览器/Custom Tabs。应用不访问供应商登录密码，不注入抓取脚本。
- 返回应用后保留当前引导步骤；使用 iOS 系统 PasteButton 或对应明确用户动作读取剪贴板，不在启动/切回时自动检查或读取内容。
- 不通过 URL query、deep link 或外部统计服务传递 Key，不要求用户把 Key 发给客服。
- 默认供应商和模型由应用提供已经验证的配置；高级选项折叠。暂不新增其他供应商，仅预留适配接口。
- Key 替换采用安全写入成功后再切换，写入失败保留旧值；清除同时清理内存与安全存储。清除本地副本不等于撤销供应商的 Key，需要时提供官方管理入口。
- 不修改用户剪贴板的其他内容，不默认导出 Key，不把 Key 加入备份、照片分享或检查记录。

## 错误对应的下一步

| 情况 | 用户提示与动作 |
|---|---|
| 格式明显不完整 | 检查是否复制了完整 Key；保留输入，不发送请求 |
| 身份验证失败 | 提示检查 Key 有效性，并允许更换 |
| 无权限/地区不可用 | 明确可能是权限或地区限制，提供相应官方帮助；不承诺重新生成就能解决 |
| 模型不支持/不可用 | 引导选择受支持的默认模型；不要求重新注册账号 |
| 限流或额度不足 | 提示稍后重试或查看供应商配额，不自动重试可能付费的调用 |
| 网络超时 | 保留凭据和原图，可取消后重试 |
| 安全存储失败/设备锁定 | 不显示保存成功，不退回明文存储；解锁或重试 |

免费配额只用于符合该模型与地区规则的账号；不宣传“永久免费 AI”。照片的上传用途说明与明确同意必须在首次发送前完成。[计费](https://ai.google.dev/gemini-api/docs/billing)、[数据处理条款](https://ai.google.dev/gemini-api/terms)

## 验收标准

在目标地区分别使用新账号和已有账号实走，记录完成时间、离开应用次数及卡住的步骤；不会以未登录官网的页面加载成功当作注册成功。

功能验收包括：跳过引导、本机保存、退出重进、进程重启、旧 Key 替换失败恢复、主动清除、取消输入、无效 Key、模型错误、限流和地区错误。记录中不包含用户凭据。两端都需真机测试，侧载重签名额外验证 Keychain 可访问性。

首发地区尚未确认，不能把 Gemini 定为所有用户的通用最简注册入口。技术存储和模块边界见 [ARCHITECTURE.md](ARCHITECTURE.md)。
