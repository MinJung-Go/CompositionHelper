# iOS 色彩工作室界面 review

> 此报告只针对 `1d9a096` 及之前的编辑器改版，不含后续真人清单。当前版本状态见 [RELEASES.md](../testing/RELEASES.md)。截图曾上传至文内 CI 的 `editor-review` artifact，受保留期限限制。

日期：2026-09-09

## 修改范围

以用户提供的真机截图为依据，重做 `ColorEditorView`。保留照片导入、前后对比、手动调色、AI 调色、撤销、重置和保存副本；没有改动调色算法、API 地址或签名配置。

## 发现与处理

1. **样片区域空白**：独立 JPG 被按资源名加载。改为从 Bundle 中明确读取 JPG，并显示缺失资源占位。四张缩略图在模拟器截图中均可见。
2. **照片出现得太晚**：大型换图按钮、样片与来源说明占据首屏。改为紧凑换图栏，样片移入单独面板，来源默认折叠；照片成为主要内容。
3. **竖图容易挤出操作区**：预览按图片比例与可用高度约束显示，保留完整画面，对比分界线限制在实际照片范围内。
4. **忙碌状态不清楚**：进度、取消、错误与渲染重试移到固定底部区域，避免只看到一组禁用按钮。
5. **操作样式与对比度不足**：金色主按钮、深色次按钮，明确区分正常、按下及禁用状态；底部采用实色背景。
6. **第一轮最大辅助字体截图暴露排版问题**：换图文字被挤成竖排。针对辅助字体采用有无障碍标签的图标操作，减少顶部占用；主要按钮允许纵向排列。
7. **细小参数显示**：保留四位小数，避免小幅 RGB 调整在控件上被四舍五入成零。

## 代码检查

- 保存仍受 `editor.ready` 约束，只有预览与最新参数、强度一致且没有忙碌任务才可保存。
- 照片替换与手动参数操作在任务进行时禁用，取消入口保持可用。
- 空白 API Key 先进入设置；设置使用独立视图与系统 dismiss。
- `.sheet(item:)` 表达互斥的样片/设置面板。
- 样片解码结果缓存，避免每次 Slider 更新都重新读取 JPG。
- 截图用启动参数仅在 DEBUG 编译启用；Release 正常进入原应用主页。
- 图像原始数据、调色算法、撤销记录与保存逻辑沿用原有实现。
