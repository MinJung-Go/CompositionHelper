## 2. 功能差异台账（以代码检查为依据）

| 功能 | Android | iOS | 统一结论 / 下一步 |
|---|---|---|---|
| 实时相机、构图辅助线、透明度和颜色 | 已有实现 | 已有实现 | 按同一场景核对线型、方向、裁切；未完成真人对照 |
| 智能构图建议 | ML Kit / CameraX 路径 | Vision / AVFoundation 路径 | 不要求内部算法相同；要求建议可理解、模式可切换，待实测 |
| 拍摄结果与保存 | 快门后保存原片并进入后续流程 | 拍摄结果页再保存 | 流程差异仍存在，不能宣称操作完全一致 |
| 四张内置样片 | 已有实现 | 已修复 Bundle JPG 缩略图加载 | 需要真人逐张打开与方向核对 |
| AI 调色、手动精调、强度 | 已有实现 | 已有实现 | 同配方比较输出；原生 UI 和部分文案仍不同 |
| 原图 / 调色后 / 对比 | 已有实现 | 新版照片优先布局 | Android 未同步本次 iOS 美化 |
| 撤销、重置、渲染就绪后保存 | 已有实现 | 已有实现 | 验证忙碌、错误、取消后的状态一致性 |
| 渲染变化统计、进度展示 | 与 iOS 表达不同 | 固定底部进度，详情有变化统计 | 待统一展示规范，不据成功提示判定调色有效 |
| 拍摄检查清单 | 本轮新增 | 本轮新增 | 条目和状态语义统一；原生控件样式允许不同 |
| 清单记录跨平台同步 | 未实现 | 未实现 | 当前设计只保存在本机，导出文本可供人工汇总 |
