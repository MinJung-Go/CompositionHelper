# 应用内拍摄检查清单：真人使用说明

从相机顶部的清单图标进入“拍摄检查清单”。按拍摄前、取景拍摄、拍摄后三个阶段逐项实际操作，再点击每项的状态选择结果。

- **待检查**：尚未实际核对。
- **已确认**：本人操作并观察到符合要求的结果。
- **有问题**：未满足要求，请在底部写明项目和现象。
- **不适用**：本次没有执行，例如未使用调色；请在备注说明原因。

进度只统计“已确认”，不会把有问题和不适用算作通过。应用不会根据快门或 AI 返回结果自动改变状态。

关闭清单或重启应用后，本轮进度和备注保存在本机。**新一次拍摄不会自动清空**：先导出要保留的记录，再选择“开始新一轮检查”并确认重置。取消重置会保留记录。卸载或清除应用数据可能丢失记录；系统备份/恢复也可能影响保留结果，目前没有账号同步。具体平台差异见 [数据与隐私说明](../reference/DATA_PRIVACY.md)。

“导出检查记录”通过系统分享面板生成文本，包含所有项目、状态、备注、平台、应用版本与导出时间。选择接收应用后才会分享；记录不包含照片或 API Key。

项目标准见 [SHOOTING_CHECKLIST.json](../reference/SHOOTING_CHECKLIST.json)。软件发布验收另见 [跨平台开发验收表](../testing/CROSS_PLATFORM_ACCEPTANCE.md)，本清单是人实际拍摄时使用的操作记录，不是自动测试报告。
