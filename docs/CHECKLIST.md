## 8. 新增需求：拍后智能分析与调色（首版已实现，待真机验收）

用户目标：对刚拍好的照片或相册中的已有照片，自动分析画面并生成合适的调色效果，允许预览、微调后保存。

首版流程：拍照完成/选择原图 → 智能分析 → 一键调色预览 → 原图对比与强度调整 → 保存副本。

### 首版功能

- [x] 接通原图入口：相机保存成功后进入“智能调色”页面，使用返回的照片 URI；相册选图后也能进入同一编辑流程。
- [x] 分析曝光、亮暗分布、对比度、白平衡偏色与饱和度，给出简短且与实际调整一致的建议，例如“提亮阴影，减轻偏黄”。
- [x] 根据分析结果生成调色参数，覆盖曝光、对比度、高光、阴影、色温、色调和饱和度；首版默认以自然还原为目标。
- [x] 一键应用建议并展示预览，支持按住查看原图或前后对比。
- [x] 提供整体效果强度和基础参数微调，支持重置回原图；连续调整应从原图和参数重新渲染，避免反复叠加损失。
- [x] 明确显示分析中、预览生成中、导出中及失败状态；支持取消和重试，重新选图后旧分析不得覆盖新图片。
- [x] 以原始分辨率保存调色副本至相册，保留原片；正确处理方向、色彩空间，并核对预览与导出颜色一致性。

实现位置：`color/ColorAdjustment.kt`（算法）、`color/ColorPhotoStore.kt`（图片读取与导出）、`color/ColorEditorScreen.kt`（编辑页）。自动应用自然调色建议，支持七项参数、效果强度、重置与保存副本。API 26+ 解码统一为 sRGB；API 24–25、EXIF 各方向及预览/导出一致性仍需设备验证。以上勾选表示实现已接通，不表示设备验收完成。
